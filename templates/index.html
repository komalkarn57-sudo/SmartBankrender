About SmartBank

SmartBank is a student-developed banking application created using Python, Flask, MySQL, HTML and CSS.

The application demonstrates basic banking operations such as account creation, login, balance management, money transfers and transaction records.

Python libraries such as Pandas and NumPy can also be used to analyze transaction data.
